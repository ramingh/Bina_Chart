# ورود سورس اصلی نمودارساز

مخزن اصلی فعلاً فایل‌های معرفی و ابزار ورود ZIP دارد. این دستورالعمل فقط یک‌بار برای انتقال کامل سورس لازم است.

1. از صفحه مخزن GitHub، **Add file → Upload files** را انتخاب کنید.
2. فایل `BinaPivotChart_Designer_Viewer_v2.12.0.zip` را با همان نام به مسیر `imports/` اضافه کنید و Commit بزنید. برای ساخت پوشه می‌توانید ابتدا در مسیر `imports/README.md` یک فایل بسازید، سپس ZIP را در همان پوشه بارگذاری کنید.
3. پس از بارگذاری، Workflow با عنوان **Import official BINA PivotChart ZIP** اجرا خواهد شد. در صورت فعال بودن مجوز نوشتن GitHub Actions، فایل‌های واقعی HTML/CSS/JavaScript/JSON/ASMX در ریشه مخزن استخراج و Commit می‌شوند.
4. نتیجه را از قسمت **Actions** بررسی کنید. صرف بارگذاری ZIP به معنی پایان انتقال سورس نیست؛ باید Commit ورود سورس و فایل‌های واقعی دیده شوند.

نکته: آرشیو بارگذاری‌شده نام نسخه ۲.۱۲ دارد ولی برخی توضیحات و عنوان فایل‌ها هنوز «۲.۱۰» هستند. ابزار ورود فایل‌ها را تغییر نمی‌دهد.

در صورت غیرفعال بودن Actions یا خطای مجوز نوشتن، بایستی اجرای Workflow یا دسترسی write مربوط به Actions در تنظیمات مخزن فعال شود.
