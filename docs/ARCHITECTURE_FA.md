# معماری Bina_Chart

این سند قرارداد طراحی مورد توافق است و **ادعای موجود بودن فایل‌های اجرایی در مخزن فعلی را ندارد**.

- **Designer:** تعریف محور X چندسطحی، فیلترها، محورهای Y، Series و ویژگی‌های بصری.
- **Viewer:** نمایش نمودار طبق تنظیمات JSON ذخیره‌شده.
- **Renderer:** موتور ترسیم سازگار با Designer و Viewer.
- **Data Adapter:** تبدیل داده برگشتی SQL Runner، گزارش‌ها یا IndexedDB به ورودی نمودار؛ جدا از Renderer.

## قراردادهای سازگاری

1. قالب JSON بین Designer و Viewer باید بدون تغییر معنی قابل جابه‌جایی باشد.
2. خاموش کردن گزینه «نمایش Series» نباید مقدار Series ذخیره‌شده در JSON را حذف کند.
3. نمودار باید در کادر responsive خود نمایش یابد؛ بدون اسکرول داخلی افقی/عمودی غیرضروری.
4. پیش از هر بازنویسی یا refactor، باید خروجی نسخه مرجع v2.10.0 مقایسه و تست شود.
5. فونت IRANYekanX-Light.ttf در ریشه پروژه میزبان فراخوانی می‌شود؛ باینری فونت به مخزن اضافه نمی‌شود.
