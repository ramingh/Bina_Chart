# Bina_Chart

مخزن مستقل نمودارساز پروژه **BINA** (PivotChart Designer / Viewer).

> **وضعیت فعلی:** ساختار و مستندات اولیه ثبت شده‌اند. **سورس عملیاتی هنوز به این مخزن منتقل نشده است.** نسخه مرجع برای انتقال: `BinaPivotChart_Designer_Viewer_v2.10.0.zip`. پس از دسترسی به فایل اصلی، سورس به‌صورت کامل بررسی و وارد می‌شود؛ کدها از روی حافظه بازنویسی نخواهند شد.

## قابلیت‌های نسخه مرجع 2.10.0

- Designer و Viewer مستقل با قرارداد JSON
- محور X چندسطحی، Drag & Drop و فیلتر کنار فیلد
- مقادیر Y با SUM، AVG و COUNT
- حالت‌های 2D و 3D-نما، شامل Pie
- نمایش مقدار، رگرسیون و R²، تنظیم فونت و رنگ
- امکان نمایش/مخفی کردن Series بدون حذف انتخاب آن از JSON
- محدود کردن نمودار SVG به کادر نمایشی و حذف اسکرول داخلی

## ساختار مخزن

- `src/` — سورس واقعی کامپوننت‌ها پس از انتقال
- `examples/` — صفحات اجرای نمونه (پس از انتقال)
- `tests/` — آزمایش‌ها و نمونه‌های سازگاری (پس از انتقال)
- `docs/ARCHITECTURE_FA.md` — قرارداد معماری و وابستگی‌ها
- `docs/CHANGELOG.md` — وضعیت نسخه‌ها

## قواعد پروژه

1. نسخه `v2.10.0` مبنای توسعه است؛ بدون دسترسی به سورس واقعی آن هیچ جایگزین حدسی وارد نخواهد شد.
2. Designer و Viewer مستقل می‌مانند و تنظیمات JSON باید سازگار باشد.
3. موتور ترسیم نباید وابستگی اجباری به SQL Server یا IndexedDB داشته باشد؛ اتصال داده از طریق Adapter انجام می‌شود.
4. فایل فونت `IRANYekanX-Light.ttf` متعلق به پروژه میزبان است و در مخزن قرار نمی‌گیرد.
5. این مخزن مستقل از [Bina](https://github.com/ramingh/Bina) توسعه می‌یابد.

## گام بعد

فایل `BinaPivotChart_Designer_Viewer_v2.10.0.zip` را در این گفت‌وگو بارگذاری کنید تا سورس واقعی بدون از دست دادن تغییرات قبلی به مخزن انتقال یابد.
