# BINA PivotChart Designer / Preview / Viewer v2.10.0

کامپوننت مستقل و آفلاین HTML/CSS/JavaScript برای نمودارهای مالی، با رابط مشابه PivotChart در Access 2010. هیچ فایل از Grid، Report Designer، Sidebar و Bina_Bank.js تغییر نمی‌کند.

## اجرا

1. پوشه را استخراج و `index.html` را در Edge یا Chrome باز کنید.
2. تب «محورها X/Y»: فیلدهای X، شاخص‌های Y و تابع SUM/AVG/COUNT را تنظیم کنید. تیک «نمایش بخش Series (اختیاری)» پیش‌فرض خاموش است؛ فعال‌شدن آن بخش Series را روی Designer و Viewer نمایش می‌دهد و عرض خود نمودار اندکی کاهش می‌یابد.
3. تب «نوع و سه‌بعدی»: شکل نمودار را از میان ۱۰ نوع انتخاب کنید؛ کمبوباکس 2D/3D کوچک‌تر شده است. «چهارگوش» اکنون «ستونی» نام دارد.
4. برای مشاهده خروجی مستقل، کلید «پیش‌نمایش» را بزنید. `preview.html` داده‌های پیش‌نویس را از Designer دریافت می‌کند؛ `viewer.html` برای خواندن تنظیمات ذخیره‌شده است.
5. تنظیمات را به صورت JSON دانلود یا در سرویس ASMX خود ذخیره کنید. نمونه `samples/pie-demo.json` را می‌توانید از بخش «بارگذاری JSON» وارد کنید.

## Pie

- برش‌های نمودار از گروه‌های محور X ساخته می‌شوند و مقدار هر برش از **اولین فیلد Y فعال** بر اساس SUM/AVG/COUNT/... به‌دست می‌آید. برای خروجی خواناتر، بهتر است هنگام انتخاب Pie فقط یک فیلد X داشته باشید.
- مقادیر صفر یا منفی برای مساحت دایره معنی ندارند و در Pie نمایش داده نمی‌شوند. در Pie، در صورت روشن‌کردن Series، آن فیلد برای انتخاب/فیلتر مقادیر قابل استفاده است، نه تقسیم نمودار به چند سری مجزا.
- در حالت 3D، عمق به شکل سه‌بعدی‌نما با SVG نمایش داده می‌شود، نه چرخش WebGL.
- کاربر Viewer می‌تواند با کمبوباکس‌های X، فیلتر کند و در صورت اجازه تغییر رنگ، برش موردنظر را رنگ‌آمیزی کند.

## محدودسازی اندازه نمودار

نمودار SVG متناسب با کادر اختصاص‌یافته رسم می‌شود و **درون کادر اسکرول افقی یا عمودی ندارد**. زمانی که دسته‌ها بسیار زیاد باشند، فضا بین همه آن‌ها تقسیم می‌شود و نوشته‌ها ممکن است متراکم شوند؛ فیلتر کمبوباکس X برای کاهش تعداد دسته‌ها توصیه می‌شود.

## فایل‌ها

- `index.html` و `js/BinaPivotChart.js`: Designer
- `preview.html` و `viewer.html` و `js/BinaPivotViewer.js`: پیش‌نمایش و نمایش مستقل
- `js/BinaPivotRenderer.js`: موتور SVG مستقل
- `css/BinaPivotChart.css`: استایل
- `js/demo-data.js`: اطلاعات نمونه محلی
- `server/BinaPivotChartService.asmx`: نمونه سرویس (نیازمند تنظیم و آزمایش روی IIS)
- `samples/`: JSONهای نمونه و اتصال داده

JSON با `schema: bina-pivotchart` و `version: 2` ذخیره می‌شود و تنظیمات نسخه‌های قبلی حفظ شده‌اند. رندر و کنترل‌ها در مرورگر آزمایش شده‌اند؛ وب‌سرویس ASMX روی سرور واقعی شما آزمایش نشده است.
